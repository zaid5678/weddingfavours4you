# Wedding Favours 4 You — Website

Luxury wedding favours & personalised chocolates.

## Tech Stack
Static HTML/CSS/JS — no build step required.

## Deployment (Netlify)
1. Push to GitHub (already configured)
2. Go to netlify.com → New site → Import from GitHub
3. Select this repository
4. Build command: (leave empty)
5. Publish directory: `.`
6. Deploy!

## Form Email Notifications
After deploying to Netlify:
1. Go to your Netlify dashboard → Site → Forms
2. Click on the "contact" form
3. Go to Form notifications → Add notification → Email
4. Enter: personalisedchocolatesltd@yahoo.com
